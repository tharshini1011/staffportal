# AttendX – RIT Attendance System

## Deploy in 3 minutes (FREE) using Netlify

### Method 1 – GitHub + Netlify (Recommended)

1. Go to https://github.com and create a free account
2. Click "New repository" → name it `attendx` → Create
3. Upload ALL files in this folder to the repository
4. Go to https://netlify.com → Sign up free → "Add new site"
5. Choose "Import from GitHub" → select `attendx` repo
6. Build command: `npm run build`
7. Publish directory: `dist`
8. Click "Deploy" → Your site is LIVE in ~2 minutes!

Your URL will be: https://attendx-rit.netlify.app (or similar)
You can set a custom domain later.

---

### Method 2 – Vercel (Easiest)

1. Go to https://vercel.com → Sign up with GitHub
2. Click "New Project" → Import your GitHub repo
3. Vercel auto-detects Vite → just click "Deploy"
4. Done! URL: https://attendx.vercel.app

---

### Method 3 – Run locally first (to test)

```bash
npm install
npm run dev
```
Open http://localhost:5173
